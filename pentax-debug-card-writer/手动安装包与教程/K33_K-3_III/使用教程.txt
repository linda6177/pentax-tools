K-3 III 彩色版 v2.20 · Service / Factory 菜单与脚本模式更正
验证状态：Factory / Script / 四季原始函数核验；Factory 实机待确认。
Service 入口已有用户实测；Factory 入口、Script 菜单、四季命令已做固件原始函数离线验证，Factory 实机入口与脚本重启持久化待确认。

为什么原来找不到 Script
[OPEN_DEBUG_MENU] 打开的是 Service Menu。其页面没有 FW Setting 1/2。
[OPEN_FACTORY_DEBUG_MENU] 才对应 Factory Menu，其中 FW Setting 1 → Script 是独立的脚本开关。不是把相机型号或 DEVELOP.MOD 改成 GR，也不是 Service Menu 中遗漏翻页。

1. 打开 Factory Menu
工程模式区选择 K-3 III，再选“Factory Menu · 脚本开关入口（待实机）”；四季滤镜区的 K-3 III“工程菜单入口”也已改为这一方案。
工具写入卡根目录 00078420.582（内容仅 [OPEN_FACTORY_DEBUG_MENU]，ASCII/CRLF）及原有 10 字节 DEVELOP.MOD。
写入口时会备份并移走已知 script/startup.ttl，避免它抢先执行；其他未知脚本需先核对并手动移走。
安全弹出，装回你已成功进入 Service Menu 的同一张卡、同一卡槽；关好卡仓，按住 MENU 不放再开机（已实机确认）。不要再用卡仓打开的方式。
预期标题应为 Factory Menu。进入 FW Setting 1，找到 Script 并切换为启用状态，正常确认退出、关机保存。Camera Mode 和 Script 为不同设置，不必为了找 Script 改动其他项目。
若仍是 Service Menu，先在电脑确认卡上命令确实已换成 OPEN_FACTORY_DEBUG_MENU、没有 .txt 后缀，并核对是否放在正确卡槽；保留屏幕照片与固件版本。

2. 探测脚本
在工具选择 K-3 III → 只写标记探测。工具会备份并移走已知工程入口文件；安全弹出后普通开机，关好卡门，不按 MENU。
关机取卡检查 script/K33_SCRIPT_PROBE_OK.txt。必须是本次新产生的文件；旧标记不能证明本次执行成功。
先用探测验证 Script 开关在普通重启后生效，再运行滤镜脚本。

3. 四季滤镜
选择 K-3 III → 启用选中四季，可单选、多选或全选。未勾选的季节不会自动清除。
命令后缀为 Harubeni / Katen / Kyushu / Fuyuno。该型不能混用 K12 的 Spring / Autumn / Winter 后缀。
本轮没有修改四季脚本算法。请检查机内四季选项并拍 RAW+JPEG；RETURNED 标记只表示脚本走到调用之后，不等于已成功激活。
K12 已实测离开脚本卡重启会失效；K33 的重启、换镜头、保存设置行为待实测。K-3 III Monochrome 不在本方案范围。

4. 备选与退出
若只需直接开脚本，可用“仅开启脚本模式”写 [SCRIPT_EN_MODE EN]，沿用工程触发条件。解析器和 Script 状态提交函数均已验证，但整机启动/保存未完整模拟。
关闭时可在 Factory 的 Script 项切换关闭，或用备选 [SCRIPT_EN_MODE DIS]。先移走启动脚本，再测试关闭后的正常启动。
Service Menu 入口保留在工程模式区，可按原方案恢复；它与 Factory 入口共用同一文件名，卡上一次只放一种命令。

5. 菜单用途
Factory 有 FW Setting、显示/硬件测试、AF、数据导入导出、初始化、版本等页。Service 仅保留较少维护项目。
SD → Camera 的 Adjust Data、Initialize 等会改变校准/用户数据，不属于开脚本或开滤镜步骤，勿作为探索入口随意执行。
完整菜单表及证据见随包“K33工程菜单核查”。本工具只写卡文件，不执行数据导入、校准、初始化、刷固件或镜头 ROM 写入。
