K-1 II / K12 · 四季滤镜脚本教程
版本范围：实机 2.50 / 分析 2.51
验证状态：用户实测四季启用成功

建议顺序：工程入口 → 在机身打开 SCRIPT EN MODE → 探测脚本 → 启用选中四季。

1. 工程入口
选择“工程模式”功能区的对应机型，或本区“工程菜单入口”，写入根目录 00078400.597 和 DEVELOP.MOD。
写入口方案时，程序会先备份并移走已知的 startup.ttl，避免脚本抢先运行挡住工程入口。未知脚本会拦截并提示手动核对。
正常关机后装卡；双卡槽使用卡槽 1。K-3 III / K-70 / KF：关好卡仓，按住 MENU 不放再开机（已实机确认）。K-1/K12：按住 MENU、卡舱门打开时开机。
进入后找到 SCRIPT EN MODE 设为 EN 并正常确认。首次可沿用 K12 成功时的 DEBUG=EN、SCRIPT=EN；日常只开 SCRIPT 的组合仍需本型号重启实测。

2. 找不到脚本开关时
可选择“开启脚本模式（备选）”，仅写入 [SCRIPT_EN_MODE EN] 模式文件及 DEVELOP.MOD，再按该机型工程入口条件启动。该指令解析已经验证，但完整启动应用/保存路径仍待实机。不要把它当成已验证的一键启用。

3. 先探测
选择“只写标记探测”写卡，安全弹出后普通开机，不按 MENU，卡舱门正常关闭。程序会备份并移走已知根目录工程触发文件，避免反复进入菜单。
关机后在电脑查看 script/K12_SCRIPT_PROBE_OK.txt。只有本次新产生的标记才能证明执行；重测时核对时间或先备份旧标记。
没有标记时先核对 SCRIPT 开关是否保存、卡槽及启动条件，不要继续盲试滤镜命令。

4. 启用四季
选择“启用选中四季”，勾选春、夏、秋、冬，或按“全选”；程序仅发送已勾选季节的命令。未勾选的季节保持当前状态，不会自动撤销。
写卡成功只代表卡内文件正确，并不等于相机已激活。安全弹出卡，普通开机，在自定义影像菜单检查 HARUBENI / KATEN / KYUSHU / FUYUNO，并分别拍摄 RAW+JPEG。
脚本会写 BEGIN / RETURNED 标记。RETURNED 仅代表调用走到末尾，不保证命令返回成功或实际拍摄成功。

5. 保留、撤销与再次进入工程菜单
K12 已实测：无脚本卡重启后强制启用消失，因此日常需保留启动脚本。其他三机型重启、换镜头表现仍待实测。
“撤销选中四季”只撤销勾选季节；全选后撤销可清除全部四季强制标志。运行后再移走脚本。
需要进入工程菜单时重新写“工程菜单入口”，会备份并移走已知启动脚本。已知其他机型触发文件也先备份移走，防止混用。
要关闭脚本，可在机身设 SCRIPT EN MODE=DIS；或使用“关闭脚本模式（备选）”，完整流程仍待实机。

6. 机型差异
K-1 与 K12 的四季命令名称和脚本内容可共用，工程模式文件名不同；本程序按机型写入，不会混用。
K-3 III 使用 Harubeni / Katen / Kyushu / Fuyuno 命令后缀；K-1、K12、KF 使用 Spring / Katen / Autumn / Winter。
K-3 III Monochrome 不在四季滤镜适配范围。

7. 文件与备份
所有激活操作只写存储卡文件，不格式化、不修改照片、不刷固件、不写镜头 ROM。被替换/移走文件保存在卡内 Pentax_Debug_Backup_*，保留原有相对目录。
script/startup.ttl 是 ASCII、无 BOM、CRLF；DEVELOP.MOD 是原始 10 字节二进制，不能用记事本另存为文本。
