# 宾得工模写卡工具（PENTAX 工程模式 / 四季滤镜）

给 PENTAX 相机写“工程模式（Debug / Development Menu）入口文件”的 Windows 小工具，纯本地写卡，不刷固件、不改照片。

## 当前版本：v1.3（2026-10-21）

v1.3 依据**官方固件元数据**补齐 / 更正了两款机型的工程模式入口文件名：

| 机型 | 入口文件 | 依据 |
|---|---|---|
| K-70 | `00078370.586` | 官方 k70_v116 / v1.15 / v1.11 ROM 元数据 cpu=586、public=78370 |
| KP | `00078380.581` | 官方 kp_v131 / v1.10 ROM 元数据 cpu=581、public=78380 |

- 原公开教程的 `00077770.524`（K-70）与公开清单的 `00078389.581`（KP）在对应官方镜像中都不存在，作为“公开旧文件名（备用）”方案保留。
- 两机型 `DEVELOP.MOD` 仍为 10 字节原厂校验值 `07 01 2C 1F 10 03 1E 16 05 2D`。
- 两机型固件内均无 `ForcedActivation` 四季滤镜命令，不列入四季机型；四季功能区仍为 K-1、K-1 II/K12、K-3 III、KF（4 机型 × 34 方案）。

详见 [`更新记录_1.3.md`](更新记录_1.3.md) 与 [`固件核验/说明.md`](固件核验/说明.md)。

## 用法

1. 运行 `宾得工模写卡工具.exe`。
2. 选机型 → 选方案 → 选存储卡盘符 → 「写入工程模式文件」。
3. 按 `使用说明.txt` / 对应机型的 `使用教程.txt` 在相机上开机进入菜单。
4. 退出时把 `DEBUG MODE` 改回 `DIS`，关机取卡，删掉触发文件。

手动装包在 `手动安装包与教程/`（也打包成 `手动安装包与教程.zip`），不运行 exe 也能用。


自测只使用临时目录和模拟照片，不写存储卡。

## 边界与免责

- 所有工程文件名、命令字符串均来自官方固件的离线解码；**没有实机验证菜单是否真的出现**。
- 工具只写卡，不刷固件、不做校准写入、不碰机身数据。
- 写卡成功不等于机身进入工程模式；请按教程操作并自行承担风险。
- 四季滤镜脚本仅对已核实的四款机型提供，其他机型不要套用。
